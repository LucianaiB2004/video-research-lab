# 动作复刻视频｜使用说明

发送动作参考视频、新人物或新主体参考图，以及 `动作复刻视频提示词.md`：

```text
提取原视频中人物 00:02—00:08 的舞蹈动作，让我上传图片中的人物完成。
复刻精度：SEMANTIC_EXACT。
保留动作方向、节拍、重心和手部轨迹。
使用新的舞台背景，不保留原人物、服装和场景。
摄影机：保留原视频中展示动作所需的机位关系。
```

`SEMANTIC_EXACT` 通常比机械追求完全相同的二维轨迹更稳定，因为不同人物的体型和肢体比例需要适配。

本功能负责动作迁移。只替换人物但保留整支视频时使用 `03-替换主体视频`；只复制摄像机运动时使用 `09-运镜复刻视频`。

## XML 系统协议使用方式

- 复制提示词文件中完整的 `<system_protocol>...</system_protocol>`，不要只复制其中一个章节。
- 平台有独立 System Prompt 输入框时，将完整协议放入该输入框；没有独立输入框时，将它作为对话中的第一段指令。
- 保留 XML 标签和 CDATA 边界，只替换协议明确要求用户提供的素材、参数与占位信息。
