# 替换场景视频｜使用说明

发送原视频、目标场景参考图和 `替换场景视频提示词.md`：

```text
把原视频中的白色摄影棚替换成夜晚的高级酒店套房。
保留人物、服装、香水、动作、镜头顺序和时长。
按照酒店灯光重新计算人物受光、产品反射和阴影。
环境声改成安静室内声，保留原对白和配乐。
输出模式：AUTO。
```

如果摄影机在原视频中大范围移动，最好提供目标场景多个角度或场景视频。单张场景图只能可靠约束其中可见的视角。

本功能用于更换环境。只想换人物或商品时使用 `03-替换主体视频`；只改变画面表现媒介时使用 `07-视频风格转换`。

## XML 系统协议使用方式

- 复制提示词文件中完整的 `<system_protocol>...</system_protocol>`，不要只复制其中一个章节。
- 平台有独立 System Prompt 输入框时，将完整协议放入该输入框；没有独立输入框时，将它作为对话中的第一段指令。
- 保留 XML 标签和 CDATA 边界；本次素材与参数放在独立用户消息，不要逐个替换协议中作为输出示例的占位符。
- 协议交给分析/规划模型；再把它产出的图像或视频提示词及对应素材交给生成工具。XML 标签不会改变消息权限。
