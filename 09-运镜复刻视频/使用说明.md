# 运镜复刻视频｜使用说明

发送运镜参考视频、新主体或新场景素材，以及 `运镜复刻视频提示词.md`：

```text
只复刻原视频 00:01—00:07 的摄影机运动和构图变化。
新主体：我上传图片中的香水。
新场景：黑色镜面摄影棚。
不保留原视频的人物、产品、背景和声音。
保留原运镜的揭示顺序和速度变化；空间不兼容时以构图效果优先适配。
```

模板复刻的是可观察摄影效果。普通视频没有相机三维轨迹和精确焦距数据时，无法证明物理路径完全相同。

需要连人物动作一起复刻时，先使用 `08-动作复刻视频` 提取动作，再把动作蓝图作为本功能的新主体动作输入。

## XML 系统协议使用方式

- 复制提示词文件中完整的 `<system_protocol>...</system_protocol>`，不要只复制其中一个章节。
- 平台有独立 System Prompt 输入框时，将完整协议放入该输入框；没有独立输入框时，将它作为对话中的第一段指令。
- 保留 XML 标签和 CDATA 边界；本次素材与参数放在独立用户消息，不要逐个替换协议中作为输出示例的占位符。
- 协议交给分析/规划模型；再把它产出的图像或视频提示词及对应素材交给生成工具。XML 标签不会改变消息权限。
