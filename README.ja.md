## プロジェクト概要

動画研究所は、AI 動画ワークフロー向けの再利用可能なプロンプトを機能別に整理したプロジェクトです。モデルやサービスではなく、参照動画の解析、最初のフレームからの動画生成、主体の置換、動画の続きを作る処理、動作やカメラワークの再現、既存プロンプトの確認といった目的から選べます。

現在は **10 種類のプロンプトワークフロー**を収録しています。プロジェクト全体は特定のモデルに依存しませんが、入力関係を明確にするため、各テンプレートでは T2VA、I2VA、FL2VA、Ref2VA などの用語を使う場合があります。利用前に対象サービスの対応機能を確認してください。

> 現在の中心はプロンプトテンプレートです。事例は段階的に追加します。実際の生成記録がないものを、検証済みの結果として扱いません。

## クイックスタート

1. 目的に合う機能を選びます。
2. 対応するプロンプトファイルと、同じフォルダーの使用説明を開きます。
3. 完全な `<system_protocol>...</system_protocol>` をコピーし、必要な動画、画像、音声、長さ、変更条件とともにモデルへ渡します。
4. 生成されたプロンプトを動画ツールで使う前に、対応状況、不足入力、未確認事項を確認します。

| 番号 | 機能 | 主な入力 | 主な出力 |
|---|---|---|---|
| 01 | [動画プロンプト逆解析](./01-视频反推/) | 完全な参照動画 | 観察可能な根拠に基づく再現プロンプト |
| 02 | [最初のフレームから動画生成](./02-首帧生成视频/) | 最初のフレーム、動きの指示、長さ | 画像から時間方向へ展開する I2VA プロンプト |
| 03 | [主体の置換](./03-替换主体视频/) | 元動画、置換する人物または物体 | 2 段階の動画設計図と再構成プロンプト |
| 04 | [最初と最後のフレームから動画生成](./04-首尾帧生成视频/) | 最初のフレーム、最後のフレーム、長さ | 2 つの基準画像を結ぶ FL2VA プロンプト |
| 05 | [動画の続き生成](./05-视频续写/) | 元動画、続きの要件 | 確認済みの終了状態から続くプロンプト |

| 08 | [動作の再現](./08-动作复刻视频/) | 動作参照動画、新しい主体 | 動作設計図と適応済みの転写プロンプト |

## 設計原則

- **機能を基準に分類：** 1 つのフォルダーが 1 つの明確な目的に対応します。
- **構造化システムプロトコル：** 各テンプレートは入力、根拠、処理、出力を名前付きタグで整理した完全な XML コードブロックです。解析モデルに渡し、その出力を動画生成ツールで使用します。
- **推測より先に根拠を確認：** 観察できる事実、利用者の変更要求、不明点を分けます。
- **時間軸の整合性：** ショット、切り替え、生成時間、元動画の時間を明示します。
- **参照素材の役割を固定：** 画像、動画、主体、音声を混同しません。
- **移植しやすい出力：** 一般的な項目名を特定サービスの正式 API として扱いません。
- **検証状態を正確に表現：** `UNKNOWN`、存在しないことの確認、対象外を区別します。

## 事例

現在、公開済みの事例は **0 件**です。[事例フォルダー](./cases/README.md)には、今後の追加に使える記録形式を用意しています。正式な事例には、入力素材、実際のプロンプト、生成条件、出力、評価、失敗した試行、既知の制限を残します。

## 現在の状態

収録テンプレートは内部構造の整合性を確認済みです。明確な生成記録が付属しない限り、すべての動画モデルとの互換性や実際の生成成功を示すものではありません。
