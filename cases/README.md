## 添加方式

1. 复制 [`_template`](./_template/README.md) 的记录结构。
2. 新目录建议使用 `case-001-short-name` 格式，编号连续递增。
3. 补充真实输入、实际提示词、生成参数、输出结果、评估和失败尝试。
4. 只有具备可复核生成记录时才标记为 `VERIFIED`；尚未生成时使用 `DRAFT`，失败结果使用 `FAILED`。
5. 在上方案例列表中添加入口，并检查所有相对链接。

发布素材前应确认自己拥有必要的使用与展示权限，并移除不适合公开的个人信息或密钥。
