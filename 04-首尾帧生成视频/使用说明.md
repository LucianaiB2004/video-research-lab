# 首尾帧生成视频｜使用说明

发送首帧、尾帧和 `首尾帧生成视频提示词.md`，并明确时长：

```text
<Picture 1> 是首帧，<Picture 2> 是尾帧。
目标时长：8 秒。
希望使用一个连续镜头。
动作要求：人物拿起桌上的香水，取下瓶盖，最终到达尾帧中的展示姿势。
Prompt 语言：中文。
```

模板会判断两帧能否连续连接，并设计中间动作、运镜、接触、遮挡和终态。最终将两张图片及 FL2VA 提示词一起提交给支持首尾帧的生成工具。

两帧中的人物身份、产品结构或场景差异太大时，模板会要求剪辑或说明无法可靠连续完成，不会用随机变形假装连接成功。

## XML 系统协议使用方式

- 复制提示词文件中完整的 `<system_protocol>...</system_protocol>`，不要只复制其中一个章节。
- 平台有独立 System Prompt 输入框时，将完整协议放入该输入框；没有独立输入框时，将它作为对话中的第一段指令。
- 保留 XML 标签和 CDATA 边界；本次素材与参数放在独立用户消息，不要逐个替换协议中作为输出示例的占位符。
- 协议交给分析/规划模型；再把它产出的图像或视频提示词及对应素材交给生成工具。XML 标签不会改变消息权限。
