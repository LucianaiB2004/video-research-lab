每份独立提交的生成 Prompt 必须包含必要的主体、时间、运动与终态。操作说明、疑点、未知标记放在正文外；不强制下游生成文本也使用 XML。

    <timeline_contract><![CDATA[
本模板可独立使用：先确认源范围、主体、开场与终态，再识别真实 Shot、持续转场、关键动作和声音。连续运镜不增加 Shot；快速事件按实际读取能力复查，不能声称执行了不可用的逐帧读取。
源时间使用原视频绝对时间，目标整片从 0 开始，每个独立生成片段也从局部 0 开始。本任务目标时长必须由用户提供续写时长，不继承源范围长度；续写从选定边界后展开，源/目标时间不作线性重映射。下述重定时公式仅适用于用户另要求调整已观察片段速度的情况：均匀重定时使用 t_target=(t_source-source_start)*target_duration/source_duration；非均匀变化逐段列对应区间，不用一个倍率掩盖停顿或删减。
源视频记录只作为证据；目标续写建立新的 Shot/Transition 时间线，不复制源片全部镜头。Shot 与持续 Transition 的输出区间按序覆盖目标范围且只计时一次；硬切是零时长边界。shots_total 只计不同 Shot，不计 Transition、Segment 或重复版本。仅有时长上限且 Shot 超限时拆 Segment，后段承接前段终态；硬切后的 Shot 独立设首帧。
源帧采用起点包含、终点不包含的区间：前镜头尾帧不能借用硬切后的画面；转场后移首帧或选取更早内容帧时，在 edit_notes 交代被跳过区间的处理。不能默默丢掉黑场、静止阶段和结尾。
]]></timeline_contract>
    <evidence_policy id="section-02" title="能力与证据边界"><![CDATA[
必须能访问源视频最后一段的连续画面和最终可见帧。音轨不可读时仍可交付视觉续写，标 PARTIAL，音频写 UNKNOWN；只有任务明确要求且缺失音频使核心目标无法成立时才阻断。只能看到封面、截图或无法定位真实结尾时输出 `BLOCKED`。

只把源视频中可确认的信息写成事实。不得猜测画外空间、人物未展示的身份、被遮挡物品、结尾后本来会发生什么。用户要求的新事件属于续写设计，不能伪称源视频已经暗示。

音频无法读取时写 `UNKNOWN`；确认无音轨写 `no_track`。时间精度按真实能力声明。
]]></evidence_policy>
    <continuation_anchor id="section-03" title="结尾状态提取"><![CDATA[
从源视频最后三分之一重点提取 `CONTINUATION_ANCHOR`：

- `source_end_time` 和最后稳定可见状态。
- 人物与物品的身份、位置、朝向、姿态、表情、持有与接触关系。
- 未完成动作的当前阶段、方向、速度、惯性和可能停止条件。
- 摄影机位置、视角、运动方向、速度和稳定度。
- 场景几何、前中后景、光线方向、天气、特效和运动元素。
- 最后可辨文字、对白、动作音、环境声和音乐相位。
- 源视频是自然结束、动作中断、淡出、黑场还是编辑切断。

区分：

- `must_continue`：已经发生且在边界仍持续的动作、摄影机或声音。
- `may_continue`：用户可选择延续的开放事件。
- `must_not_infer`：源视频没有证据、只能猜测的后续。
]]></continuation_anchor>
    <continuation_design id="section-04" title="续写设计"><![CDATA[
目标视频的 0.00 秒必须与源视频结束状态相容。使用源视频实际最后帧作为首帧时，将其定义为 `<Picture 1>`；尚未真实提取图片时，只输出首帧提取时间和静态提示词，不能声称已有图片。

采用“边界继承 → 原运动自然延续或稳定 → 用户要求的新动作启动 → 连续发展 → 目标终态”的结构。

- 保持人物身份、脸部、体型、服装、产品几何、场景布局、光线和空间关系。
- 运动中的人物、物体、布料、液体、烟雾和摄影机不能在边界突然静止或反向；需要减速时描述减速过程。
- 源视频已完成的动作不要在续写开头重复。
- 源视频以黑场或淡出结束时，区分“从最后内容状态继续”和“从黑场之后开启新镜头”，按用户意图选择。若选择更早内容帧，另列 anchor_source_time、trim_range 和 edit_notes，不能把它冒称为真实文件末帧。
- 新增人物、物品或场景必须有合理入场方式，不得第 0 秒无因出现。

默认保持一个连续 Shot。用户要求后续剪辑时，从目标视频局部时间 0 开始重新编号 Shot，后续切镜时间严格递增。
]]></continuation_design>
    <audio_continuity id="section-05" title="声音连续性"><![CDATA[
对白跨越边界时保留说话者 ID 和原语言；只有源音频或用户文本能确认的词才可写出。被截断但不确定后文的对白不得自动补全。

持续环境声需保持声场、响度趋势和空间感。动作音与续写动作同步。配乐只参考源音乐的乐器、节奏、速度和边界动态；未经授权或没有实际音频输入时，不声称复制原始信号。
]]></audio_continuity>
