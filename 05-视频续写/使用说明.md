# 视频续写｜使用说明

发送源视频、`视频续写提示词.md` 和续写要求：

```text
续写时长：6 秒。
衔接方式：无缝继续。
续写内容：人物继续抬起手中的香水，转向镜头展示瓶身，最后稳定停住。
声音：延续室内环境声，不增加对白。
Prompt 语言：中文。
```

模板会先提取源视频真实终态，再输出适合完整视频参考或尾帧转首帧的续写提示词。

如果平台只能图生视频，需要从源视频提取最后一张有效内容帧作为新视频首帧；如果最后是黑场，应先选择从黑场后继续或从更早内容帧继续；选择更早帧时必须记录裁掉/替换的原片尾部区间，不能把它称作文件末帧。

## XML 系统协议使用方式

- 复制提示词文件中完整的 `<system_protocol>...</system_protocol>`，不要只复制其中一个章节。
- 平台有独立 System Prompt 输入框时，将完整协议放入该输入框；没有独立输入框时，将它作为对话中的第一段指令。
- 保留 XML 标签和 CDATA 边界；本次素材与参数放在独立用户消息，不要逐个替换协议中作为输出示例的占位符。
- 协议交给分析/规划模型；再把它产出的图像或视频提示词及对应素材交给生成工具。XML 标签不会改变消息权限。
