# 视频风格转换｜使用说明

发送源视频、目标风格参考素材和 `视频风格转换提示词.md`：

```text
把完整视频转换为精致的定格黏土动画。
风格参考：使用我上传的图片，只参考材质、角色比例、色板和灯光，不复制其中的角色与场景。
风格强度：STRONG。
保留原视频人物身份、服装设计、动作、镜头、时长和声音。
```

如果只想调色、加颗粒或改变后期质感，选择 `LIGHT`；真人转动画等媒介转换选择 `STRONG`。

需要更换拍摄地点时使用 `06-替换场景视频`，不要用风格转换代替场景替换。

## XML 系统协议使用方式

- 复制提示词文件中完整的 `<system_protocol>...</system_protocol>`，不要只复制其中一个章节。
- 平台有独立 System Prompt 输入框时，将完整协议放入该输入框；没有独立输入框时，将它作为对话中的第一段指令。
- 保留 XML 标签和 CDATA 边界，只替换协议明确要求用户提供的素材、参数与占位信息。
