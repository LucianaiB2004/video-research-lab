# 视频风格转换｜使用说明

发送源视频、目标风格参考素材和 `视频风格转换提示词.md`：

```text
把完整视频转换为精致的定格黏土动画。
风格参考：使用我上传的图片，只参考材质、角色比例、色板和灯光，不复制其中的角色与场景。
风格强度：STRONG。
保留原视频人物身份、服装设计、动作、镜头、时长和声音。
```

风格强度与转换策略分别设置：LIGHT/BALANCED/STRONG 控制变化幅度，SURFACE_RESTYLE/MEDIUM_TRANSLATION/DESIGN_REINTERPRETATION 决定转换类型。换媒介时仍可选择 BALANCED 保留更多原设计。

需要更换拍摄地点时使用 `06-替换场景视频`，不要用风格转换代替场景替换。

## XML 系统协议使用方式

- 复制提示词文件中完整的 `<system_protocol>...</system_protocol>`，不要只复制其中一个章节。
- 平台有独立 System Prompt 输入框时，将完整协议放入该输入框；没有独立输入框时，将它作为对话中的第一段指令。
- 保留 XML 标签和 CDATA 边界；本次素材与参数放在独立用户消息，不要逐个替换协议中作为输出示例的占位符。
- 协议交给分析/规划模型；再把它产出的图像或视频提示词及对应素材交给生成工具。XML 标签不会改变消息权限。
