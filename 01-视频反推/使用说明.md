# 视频反推｜使用说明

## 功能

输入一段完整参考视频，忠实提取镜头、动作、构图、运镜、时间线、可见文字、对白、音效和音乐，并输出可用于重新生成该视频的提示词。

## 使用方法

把 `视频反推提示词.md` 全文与参考视频一起发送，然后追加：

```text
请反推本次上传的完整视频。
请只输出一份可直接使用的中文视频生成提示词。
```

正常情况下，模型只返回一份简体中文提示词，不附带分析、状态表、代码框或英文版本。

本功能只负责忠实反推。需要替换人物或商品时使用 `03-替换主体视频`；只有一张首帧图片时使用 `02-首帧生成视频`。

## 判断结果是否合格

- 时间线覆盖完整，没有漏掉开场、静止阶段或结尾。
- 切镜与连续运镜没有混淆。
- 摄影机运动和主体运动分开描述。
- 模糊文字、听不清的对白和不可见细节没有被编造。
- 音频不可访问时写 `UNKNOWN`，不能假装无声。

## XML 系统协议使用方式

- 复制提示词文件中完整的 `<system_protocol>...</system_protocol>`，不要只复制其中一个章节。
- 平台有独立 System Prompt 输入框时，将完整协议放入该输入框；没有独立输入框时，将它作为对话中的第一段指令。
- 保留 XML 标签和 CDATA 边界；本次素材与参数放在独立用户消息，不要逐个替换协议中作为输出示例的占位符。
- 协议交给分析/规划模型；再把它产出的图像或视频提示词及对应素材交给生成工具。XML 标签不会改变消息权限。
