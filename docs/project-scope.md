# 项目范围与限制

[返回中文首页](../README.zh-CN.md) · [通用使用指南](./usage-guide.md)

## 当前包含

- 10 个按功能划分的视频提示词工作流。
- 各功能对应的使用说明。
- 英文、简体中文、日语项目入口。
- 模板导航、通用使用规范和案例记录骨架。

## 当前不包含

- 视频生成模型、推理服务或模型权重。
- 某个平台的 API 封装、参数转换器或自动执行程序。
- 项目网站、在线演示、账户系统或素材托管。
- 对所有模型和平台兼容性的承诺。
- 没有真实生成记录支撑的成功案例。

## 验证边界

项目内可以直接验证的是文件结构、链接、模板字段、流程衔接和文字一致性。实际视频质量、主体一致性、物理合理性、音画同步和平台兼容性，必须通过目标模型上的真实生成记录判断。

案例只有在保存以下证据后才应标记为已验证：

1. 使用的平台、模型或版本及生成日期。
2. 输入素材的角色和必要授权说明。
3. 实际提交的完整提示词与关键参数。
4. 原始输出或可访问的结果文件。
5. 对成功点、失败点和已知限制的记录。

## 内容维护规则

- 功能目录编号保持从 01 开始连续递增。
- 一个功能目录只解决一个主要目标；跨功能流程放在文档或案例中说明。
- 修改模板后，应同步检查同目录使用说明和相关文档链接。
- 新案例使用统一记录模板，并明确区分草稿、已验证和失败状态。
