# 通用使用指南

## 标准流程

1. **确定唯一的主要目标。** 先判断本次任务属于反推、生成、替换、续写、迁移还是检查。
2. **准备必要输入。** 为视频和图片标明用途；写清期望时长、画幅、保留项、修改项和禁止项。
3. **复制完整系统协议。** 复制 `<system_protocol>...</system_protocol>` 的全部内容，不要只截取输出格式或其中一个 `<protocol_section>`。03-替换主体视频需要按顺序执行两段协议。
4. **提交素材与任务参数。** 给每个文件稳定编号，例如“视频 1：动作参考”“图片 1：新主体正面参考”。
5. **检查模型的输入确认。** 如果模型无法读取视频、缺少素材或不支持目标模式，应先补齐条件，不要把推测当作分析结果。
6. **审核输出后再生成。** 检查时间线、主体身份、动作、运镜、场景、声音和文字是否相互一致。
7. **保留实际记录。** 生成案例时保存模型与平台、参数、完整提示词、输出、失败尝试和限制。

## 常见输入模式

| 模式 | 含义 | 常见用途 |
|---|---|---|
| T2VA | 文本驱动的视频生成关系 | 没有视觉锚点的文字生成任务 |
| I2VA | 图片驱动的视频生成关系 | 首帧生成视频、人物或商品参考 |
| FL2VA | 首帧与尾帧共同驱动 | 首尾帧之间的连续过渡 |
| Ref2VA | 一个或多个参考素材驱动 | 主体、动作、运镜、场景或风格迁移 |
| AUTO | 由执行模型根据已提供输入选择路径 | 平台支持多种输入关系且用户无需固定模式时 |

这些名称用于表达素材之间的关系，不代表所有平台都使用相同字段或提供相同能力。平台参数应以其当前官方界面或文档为准。

## 素材标注建议

使用稳定、单一的素材角色，避免一句话里让同一文件同时承担相互冲突的任务。

```text
视频 1：原视频，提供时间线、动作与运镜
图片 1：新人物，提供身份、服装与外观
图片 2：目标场景，提供空间、材质与光线
目标时长：8 秒
必须保留：动作节奏、镜头轨迹
允许调整：构图空间、接触点、遮挡关系
禁止出现：原人物面部、原商品标识
```

## 输出状态的含义

- `UNKNOWN`：输入中没有足够证据，不能可靠判断。
- `NONE` 或“确认不存在”：已完成检查，并确认该元素没有出现。
- `N/A` 或“不适用”：该字段与当前任务无关。

三者不能互相替代。尤其不要为了让结果显得完整而虚构原视频中看不清的细节。

## 组合使用

- **参考视频改成新商品：** 01 或 03 的第一段提取蓝图 → 03 的第二段重构 → 10 检查。
- **保留人物并换场景：** 06 重构环境 → 10 检查主体、光影和接触关系。
- **复刻动作并改变风格：** 08 完成动作适配 → 07 转换风格 → 10 检查前后约束。
- **先续写再检查：** 05 从真实结尾继续 → 10 检查衔接帧、方向和速度连续性。
