## 未照搬的旧规则及原因

- **固定五遍播放：** 保留应完成的检查目标，不能让模型声称调用了不可用的播放、采样或记忆管理能力。
- **切镜必须双重证据：** 3.md 第 71 行的限制可能漏掉匹配剪辑或平滑叠化，改为综合判断并标疑点。
- **整份输出所有时间戳递增：** 各片段局部时间归零、DUAL 重述都是合法情形，只检查各自时间线。
- **镜头数等于输出块数：** 3.md 第 212 行不适用于 Segment 和多版本交付，按不同 Shot ID 计数。
- **第二阶段不准更改第一次切分：** 复核发现事实错误时应记录订正，不能为了保持初稿而保留错误。
- **干净参考帧可随意后移：** 如后移，必须注明实际起点并交代前面时间区间，不丢开场内容。
- **正文无损等于效果不降：** 只能证明文字保留，不能证明真实模型的识别或生成表现。
