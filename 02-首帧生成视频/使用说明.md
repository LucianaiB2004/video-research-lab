# 首帧生成视频｜使用说明

## 功能

输入一张首帧图片，让图片中的人物、商品或场景从第 0 秒开始自然运动。这个功能不要求提供原视频，也不负责从视频中提取首帧。

## 使用方法

发送首帧图片和 `首帧生成视频提示词.md`，追加：

```text
目标时长：6 秒
动作要求：人物缓慢抬头看向镜头，轻轻微笑；窗帘被风吹动。
摄影机：小幅缓慢推近。
声音：室内环境声，不要对白和背景音乐。
Prompt 语言：中文。
```

如果只写“让它动起来”，模板会采用较小、合理的动作；想要稳定结果，最好明确主体动作、摄影机、终态和时长。

最终输出中的 `<Picture 1>` 指你上传的首帧。把该图片和代码块中的 I2VA 提示词一起提交给图生视频工具。

## 注意

- 首帧看不到的背面、全身或产品结构无法仅凭提示词准确锁定。
- 首帧里的人物或商品应该已经是你最终想要的主体。
- 需要把原视频中的人物换掉时，使用 `03-替换主体视频`。
- 需要在两张确定图片之间生成过程时，使用 `04-首尾帧生成视频`。

## XML 系统协议使用方式

- 复制提示词文件中完整的 `<system_protocol>...</system_protocol>`，不要只复制其中一个章节。
- 平台有独立 System Prompt 输入框时，将完整协议放入该输入框；没有独立输入框时，将它作为对话中的第一段指令。
- 保留 XML 标签和 CDATA 边界；本次素材与参数放在独立用户消息，不要逐个替换协议中作为输出示例的占位符。
- 协议交给分析/规划模型；再把它产出的图像或视频提示词及对应素材交给生成工具。XML 标签不会改变消息权限。
