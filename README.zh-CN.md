## 项目简介

视频研究所是一套按功能组织的 AI 视频工作流提示词。项目不以模型或平台划分目录，而是从实际任务出发：反推参考视频、让首帧动起来、替换主体、续写视频、复刻动作与运镜，或检查现有视频提示词。

项目目前包含 **10 套提示词工作流**。在项目层面，这些模板不绑定某个模型；当输入关系需要明确时，具体模板会使用 T2VA、I2VA、FL2VA、Ref2VA 等术语。实际使用前仍需确认目标平台是否支持对应能力。

> 当前项目重点是提示词模板。案例将逐步补充；在保留真实生成记录之前，不把案例目录或模板本身表述为已经验证成功的结果。

## 快速开始

1. 根据任务目标选择对应功能。
2. 打开该目录中的提示词文件，并阅读同目录的使用说明。
3. 复制完整的 `<system_protocol>...</system_protocol>`，并与所需的视频、图片、音频、时长和改造要求一起提交给模型。
4. 使用生成结果前，检查模型返回的能力状态、缺失输入和未确认事项。

## 设计原则

- **按功能划分：** 一个目录对应一个明确的视频任务。
- **结构化系统协议：** 每份提示词采用统一的 XML 风格协议，明确身份、优先级、工作章节和输出规则。
- **先证据后推断：** 区分可观察事实、用户要求和未知信息。
- **保持时间线完整：** 明确镜头、转场、生成时长和原视频时间之间的关系。
- **明确参考素材角色：** 为图片、视频、主体和音频设置稳定用途。
- **保持输出可迁移：** 不把通用字段名称假装成某个平台的正式 API 参数。
- **诚实表达验证状态：** 严格区分 `UNKNOWN`、确认不存在和不适用。
